# 🤝 CONTRIBUTING GUIDE

Welcome to BusTrack Smart 🚍
Thank you for contributing to our AI-powered TGSRTC smart transportation platform.

---

# 📌 Contribution Rules

Please follow these guidelines before contributing:

✅ Write clean and readable code
✅ Use meaningful commit messages
✅ Follow project folder structure
✅ Test your code before pushing
✅ Maintain proper documentation
✅ Avoid unnecessary dependencies

---

# 🌿 Branch Naming Convention

Use:

```bash
feature/feature-name
```

Examples:

```bash
feature/live-tracking
feature/crowd-prediction
feature/auth-system
```

---

# 📝 Commit Message Format

Examples:

```bash
feat: added live bus tracking
fix: corrected ETA calculation
docs: updated README
ui: improved mobile dashboard
```

---

# 🔄 Pull Request Process

1️⃣ Fork repository
2️⃣ Create feature branch
3️⃣ Make changes
4️⃣ Commit updates
5️⃣ Push branch
6️⃣ Create Pull Request

---

# 💻 Coding Standards

## 📱 Frontend

* Use reusable components
* Follow responsive design
* Maintain clean UI/UX
* Use proper naming conventions

## ⚙️ Backend

* Keep APIs modular
* Follow FastAPI standards
* Write optimized routes
* Maintain API documentation

# 🐛 Reporting Issues

While creating issues include:

* issue title
* screenshots
* expected behavior
* actual behavior
* device/platform details
